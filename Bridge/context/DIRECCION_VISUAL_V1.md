# Direccion Visual V1

**ID:** ARCH-20260505-03  
**Proyecto:** Bridge  
**Fecha:** 2026-05-05  
**Estado:** Criterio visual aprobado para construccion

## Decision

La direccion visual de Bridge V1 sera:

**dashboard limpio, claro y sobrio, inspirado en la sensacion de orden y limpieza de Ubuntu 24.**

## Por que esta direccion si conviene

1. evita el look generico de dashboard SaaS azul sobre blanco,
2. transmite sistema serio y operativo,
3. permite leer mucha informacion sin fatiga,
4. funciona bien para operador, diseñador y cliente,
5. da identidad sin caer en exceso visual.

## Traduccion de la referencia

La referencia no debe copiar Ubuntu literalmente.

Debe traducirse en estos atributos:

1. limpieza estructural,
2. luz controlada,
3. contraste sobrio,
4. bloques bien definidos,
5. acentos medidos,
6. sensacion de sistema maduro.

## Principios Visuales

### 1. Base clara

Bridge V1 debe vivir en una interfaz clara y luminosa.

No blanco puro dominante.

Si una base clara ligeramente matizada.

### 2. Contraste serio

Los contrastes deben apoyar lectura y jerarquia.

No deben verse juguetones ni excesivamente comerciales.

### 3. Acento controlado

Se recomienda usar un acento inspirado en la familia cromatica sobria de Ubuntu:

1. terracota suave,
2. naranja quemado discreto,
3. grafito,
4. grises calidos,
5. fondos neutros ligeramente tintados.

El acento debe usarse en:

1. foco,
2. tabs activas,
3. highlights,
4. estados clave,
5. llamadas a accion principales.

No debe usarse para inundar toda la interfaz.

## Sistema de Interfaz

### Layout

1. sidebar clara y estable,
2. topbar discreta,
3. area central respirada,
4. tarjetas con bordes suaves,
5. tablas limpias y muy legibles.

### Superficies

1. fondo general claro matizado,
2. paneles ligeramente elevados,
3. separaciones suaves,
4. sombras discretas,
5. radios moderados.

### Tipografia

La tipografia debe sentirse funcional y moderna.

No ornamental.

No demasiado corporativa fria.

Debe priorizar:

1. legibilidad,
2. jerarquia limpia,
3. densidad comoda para dashboard.

## Intencion por Rol

### Operador

Debe sentirse como cabina de control.

Mas foco en estructura, estados y accion.

### Diseñador

Debe sentirse clara y sin ruido.

Mas foco en contexto, piezas y decisiones.

### Cliente

Debe sentirse confiable y simple.

Mas foco en visibilidad, documentos y avance.

## Lo que se debe evitar

1. look demasiado oscuro,
2. glassmorphism excesivo,
3. colores neón,
4. exceso de gradientes,
5. visual de startup artificial,
6. apariencia de template genérico.

## Implicacion para construccion de hoy

Si hoy se construye una primera interfaz desplegable en Vercel, debe seguir estas reglas:

1. tema claro por defecto,
2. sidebar y layout estables,
3. acento terracota o naranja sobrio,
4. tarjetas limpias,
5. tablas legibles,
6. cero decoracion innecesaria.

## Decision Ejecutiva

La referencia correcta no es Ubuntu como marca.

La referencia correcta es:

**limpieza operativa con personalidad sobria y madura.**
