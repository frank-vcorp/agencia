# Manual de flujo en Adobe Firefly V1

**ID:** ARCH-20260526-02  
**Proyecto:** Bridge  
**Fecha:** 2026-05-26  
**Estado:** Manual operativo

## Propósito

Explicar de forma práctica dónde encontrar cada parte del flujo creativo en Adobe y cómo usarla de forma eficiente cuando el Brand Kit ya existe.

## Regla base

- Si la marca ya existe, primero se usa o se carga el Brand Kit del cliente.
- Si la pieza ya tiene prompt listo, no se reescribe desde cero.
- Firefly se usa para generar.
- Express se usa para adaptar formatos o trabajar con marca.
- Photoshop se usa para pulido fino.

## Dónde está cada cosa

### 1. Adobe Firefly

Aquí empieza la generación de la pieza.

Qué hacer:

1. Abrir Adobe Firefly.
2. Entrar a la opción de creación o generación de imagen.
3. Pegar el prompt preparado.
4. Elegir formato o tipo de resultado si la pantalla lo permite.
5. Generar variantes.

Uso principal:

- crear la primera versión visual;
- probar variaciones rápidas;
- seleccionar la base más cercana a la marca.

### 2. Brand Kit

Aquí vive la identidad de marca.

En la práctica, lo más útil es buscarlo dentro de Adobe Express.

Qué hacer:

1. Abrir Adobe Express.
2. Buscar la sección de marca, normalmente llamada Brand, Brands o Brand Kits.
3. Cargar o revisar el logo.
4. Revisar colores.
5. Revisar tipografías.
6. Confirmar estilo visual.

Uso principal:

- mantener consistencia entre activos;
- evitar que cada pieza se vea distinta;
- servir como base visual para Firefly y Express.

### 3. Adobe Express

Aquí se adaptan piezas y se usan variantes más rápidas.

Qué hacer:

1. Abrir Adobe Express.
2. Crear o abrir el formato que necesites.
3. Aplicar el Brand Kit del cliente.
4. Ajustar tamaños o versiones.
5. Sacar variantes para distintos canales.

Uso principal:

- adaptar a Feed, Story, banner o portada;
- aplicar identidad de marca;
- hacer variaciones sin rehacer toda la pieza.

### 4. Photoshop

Aquí se hace el ajuste fino.

Qué hacer:

1. Abrir Photoshop.
2. Cargar la pieza que ya va avanzada.
3. Corregir detalles visuales.
4. Ajustar fondos, recortes o limpieza.
5. Exportar la versión final.

Uso principal:

- pulido fino;
- corrección puntual;
- ajustes que Firefly o Express no resuelven tan bien.

## Flujo práctico recomendado

1. Abrir Adobe Express y revisar el Brand Kit.
2. Abrir Adobe Firefly.
3. Pegar el prompt listo.
4. Generar variantes.
5. Elegir la mejor opción.
6. Si hace falta, pasar a Adobe Express para adaptar formato o aplicar marca.
7. Si hace falta, pasar a Photoshop para retoque fino.
8. Volver a Bridge para registrar el resultado.

## Buenas prácticas

- No improvisar el estilo si ya existe Brand Kit.
- No rehacer el prompt si ya viene listo desde Bridge.
- Cambiar una cosa a la vez cuando iteres.
- Usar Firefly para explorar, no para redefinir la marca.
- Usar Express para variantes y Photoshop para detalles finales.

## Resumen corto

- Firefly: generar.
- Express: adaptar y aplicar marca.
- Photoshop: pulir.
- Brand Kit: base de consistencia visual.
